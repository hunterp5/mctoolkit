# Protein Viewer

Protein Viewer loads a crystallographic structure into an interactive 3Dmol.js canvas and lists each PDB chain (protein, ligands, metals, and solvent on that chain ID) in a Manager panel.

## Goal

Inspect a protein (and associated ligands, cofactors, metals, and waters) in 3D, then hide, select, restyle, or delete chains, or edit ligand atoms and bonds, without leaving MolManager.

## When to use

Use **Protein → Viewer** when you have a PDB, mmCIF, PDBQT, or similar coordinate file and want a Chimera/PyMOL-style look at the complex.

## Inputs / scope

A structure file on disk. This tool does not read or write the compound table.

Supported text formats include PDB (`.pdb`, `.ent`), mmCIF (`.cif`, `.mmcif`, `.mcif`), PDBQT, and PQR. Other 3D formats that 3Dmol.js can draw (GRO, MOL2, SDF, XYZ) can be opened; chain splitting is richest for PDB and mmCIF. When mmCIF includes `_chem_comp_bond`, stick and ball-and-stick styles draw double and triple bonds from that table (3Dmol's built-in CIF parser does not).

## Options

- **File → Open…** — add one or more structures to this session (does not replace files already loaded).
- **File → Save Structure…** — write the Manager-selected structure (or the last loaded file) to disk as PDB or mmCIF, including Sequence, atom, and ligand-bond edits already applied in the viewer.
- **File → Save to Session** — write the current viewer (structures, Manager styles, camera, splitters, overlays) into the open MolManager session. **File → Session → Save Session** on the main window then writes that snapshot to disk. Closing the Protein Viewer without **Save to Session** leaves the MolManager session unchanged (or keeps the last snapshot you saved). You are prompted **Save** / **Don't Save** / **Cancel** when closing with unsaved viewer changes.
- **Manager** — each file is a top-level group named after the file. Under that, components are grouped by the **PDB chain ID** written in the coordinate file (protein, ligands, metals, and waters of chain A stay under Chain A; a ligand recorded as chain L is its own Chain L group). Click a row (or an atom in 3D) to select it; the checkbox hides or shows that chain. Right-click a file, chain, or component for **Delete**, **Duplicate**, and **Add to Group**. Named groups sit at the top of the Manager and can hold polymers, ligands, and other components from any loaded file (the file tree is unchanged). Right-click a group to **Rename Group** or **Remove Group** (ungroup; structures stay). The Manager is a **dock pane**: when Gnina finishes (or **Pose Browser** is opened) with this viewer open, the pose browser fills this column. **Header arrows** (the same pager as plot panes) switch between the chain list and the pose browser. Undock it to a floating window from the pose-browser footer. Closing the Protein Viewer also closes a pose browser docked here. The pose browser is not inserted beside the compound table.
- **Log** — timestamped progress from **Tools → Prepare → Fast Prepare…**, **PDBFixer…**, **pdb2pqr…**, **Minimize…**, **Dock File…**, and **Run Gnina** in a compact strip under the 3D canvas. It stops at the Manager column. The log and the Manager both reach the bottom of the window. Prepare dialogs close when a run finishes; **Run Gnina** closes the docking window immediately and keeps writing here. Drag the splitter above the log if you need more lines.
- **Sequence** — sequence of every chain, including amino acids, **lowercase letters for residues missing from the coordinates** (SEQRES / `_pdbx_poly_seq_scheme` gaps), ligands/cofactors (`+`), metals (`*`), and waters (`~`); selected observed characters highlight in 3D. Right-click a residue one-letter code to **Mutate** it. Delete removes residues. This is the 3D-linked chain editor, not a multiple-sequence alignment. For FASTA/MAFFT alignment use **Protein → Sequence** on the main window.
- **Tools → Dock Ligand…** — open the [Gnina](tools_gnina.md) dialog. Receptor, ligand, output, search box, and the other Gnina options are stored in the session file and come back the next time that session opens.
- **Tools → Pharmacophore** — submenu: **Editor**, **Screen Table…**, and **Open…**. **Editor** is the window for placing features (click an atom, then **Add**, or type XYZ; optional atom type C/N/O/…), **From ligand**, save/clear, and **Send to Gnina**. **Screen Table…** matches packed table ensembles against the current pharmacophore. **Open…** loads a saved JSON onto the canvas.
- **Tools → Prepare → Fast Prepare…** — docking-ready cleanup for **Gnina** from a **Manager** structure or a **PDB/mmCIF file**: PDBFixer repair, pdb2pqr/PROPKA protein protonation at a chosen pH (ligand stays in for holo titration), Uni-pKa ligand protomer at that pH with optional pocket Coulomb reweight (SMILES/SDF, or mmCIF `_chem_comp_bond`), optional Manager-selected or ligand-near waters, then OpenMM restrained minimization (on by default). Uncheck **Clean up** to skip PDBFixer, or **Protonate** to skip pdb2pqr/PROPKA and Uni-pKa. After chemistry, Fast Prepare writes an **apo receptor PDBQT** (Meeko), a **crystal ligand PDB/SDF**, and a **search box** from a ligand in the **loaded structure** or from a **separate ligand file** (default 4 Å padding; shown in **View → Docking Box**). Use the file option when the ligand is not in the structure being prepared. **Open Gnina…** fills Protein → Dock Ligand → Gnina with the receptor PDBQT, numeric box, and crystal ligand for internal validation (docking ligand field left empty). **Keep ligand in prepared mmCIF** is on by default so the overlay stays holo; the PDBQT is still apo. **Restrained minimization** is on by default. You choose **protein force field** (ff14SB or ff99SB-ILDN), **ligand force field** (protein only, or GAFF2/GAFF via AmberTools — WSL on Windows), **solvation** (GBn2 GBSA, OBC2, or vacuum), **compute** (Auto GPU, OpenCL, CUDA, or CPU), salt, and whether to restrain **backbone**, **Cα**, or **backbone + ligand**. Protein-only minimization holds the ligand out of OpenMM and restores it afterward if **Keep ligand in prepared mmCIF** is on. GAFF/GAFF2 keeps the ligand in the OpenMM system (AM1-BCC charges when AmberTools `sqm` succeeds). Highest-occupancy altlocs are kept; SEQRES gaps are modeled with PDBFixer (not only PDBFixer's residue-number alignment, which misses tagged N-termini and kinase inserts). **Long missing stretches** (default more than 8 residues, such as the 6BBU N-terminal tag) are **not** rebuilt — PDBFixer cannot place them well and they are not needed for docking. SEQRES loops next to the ligand can still be skipped. You can keep selected chains, catalytic metals, or cofactors, and strip crystallization additives (EDO, GOL, SO4). Output remarks include pocket HIS/ASP/GLU names and Cα/pocket RMSD vs the start of minimization. Default output is **mmCIF** (PDB is optional) so ligand bond orders are written as `_chem_comp_bond`. **mmCIF inputs stay mmCIF for the whole Fast Prepare run**. pdb2pqr still uses a PDB/PQR scratch file internally (PQR is the format that carries per-atom charges); that is converted back immediately so HID/HIE/HIP, ASH, GLH names, hydrogens, and ligand bonds survive in the mmCIF. Per-atom pdb2pqr charges are not stored in standard mmCIF/`ATOM` records — keep the scratch `.pqr` if you need them for APBS. PDBQT is the docking export, not the archival protonation file. The result is **overlaid** on the original instead of replacing it.
- **Tools → Prepare → PDBFixer…** — repair and clean a **Manager** structure or **PDB/mmCIF file**: rebuild missing atoms/short loops, skip long disordered SEQRES tails, keep selected chains, replace non-standard residues, and strip waters/additives. Optional: keep catalytic metals or cofactors. Does **not** run pdb2pqr/PROPKA, Uni-pKa, OpenMM minimization, or Gnina export. Use this when you want a tidier crystal structure without protonation. The repaired file is **overlaid** on the original.
- **Tools → Prepare → pdb2pqr…** — protonate a **Manager** structure or **PDB/mmCIF file** with pdb2pqr/PROPKA at a chosen pH. Does **not** run PDBFixer repair or OpenMM minimization. Ligand stays in for holo titration by default; Uni-pKa can pick the ligand protomer (SMILES/SDF, or mmCIF `_chem_comp_bond`) with optional pocket Coulomb reweight. Waters already in the file are kept unless you uncheck that option. The protonated file is **overlaid** on the original.
- **Tools → Prepare → Minimize…** — restrained OpenMM minimization of a **Manager** structure or **PDB/mmCIF file** without PDBFixer/pdb2pqr. Default is **GAFF2** (AmberTools; WSL on Windows) with backbone + ligand heavy-atom restraints and GBn2 GBSA so the ligand stays in the OpenMM system. **Compute** is Auto (CUDA, then OpenCL, then CPU). The pip OpenMM wheel includes OpenCL for NVIDIA GPUs but not CUDA. **Protein only** holds the ligand out and restores it afterward. Supply ligand **SMILES** or an **SDF/MOL2** unless the file is mmCIF with `_chem_comp_bond`. The minimized structure is **overlaid** on the current file. Use this after **Tools → Prepare → Fast Prepare…** (or on an already protonated complex) when you want pose relaxation without rewriting Gnina files.
- **Tools → Prepare → Dock File…** — write Gnina files from a **Manager** structure or **PDB/mmCIF file** that is already docking-ready (no PDBFixer, pdb2pqr, or OpenMM). The output file is the **apo receptor PDBQT** (Meeko; ligands and waters stripped), plus a **crystal ligand PDB/SDF** and a **search box** beside it (default 4 Å padding; shown in **View → Docking Box**). Then opens **Protein → Dock Ligand → Gnina** with that PDBQT in **Receptor**, the numeric box filled, and the crystal ligand kept for internal validation (docking ligand field left empty), and the Dock File window closes. Use this after Fast Prepare or Minimize, or when the file is already protonated. When docking finishes, the **pose browser** docks in this Manager as a full-height page if Protein Viewer is open, or as a floating window if it is not: **header arrows** switch between the chain list and the pose browser. The table lists every pose for the current ligand (click a row to select it), and **← / →** switch among docked ligands. The 3D pane shows the ligand pose; browsing a pose also draws it in the pocket **next to the crystal ligand** (docked pose carbons are magenta). **Pose Browser Settings → Add pose to Viewer** (or **Add all poses**) pins those poses as Manager structures so you can hide, restyle, or save them with the complex.
- **Checkbox** — hide or show a chain.
- **Click** a Manager row — select that chain and highlight it. **Click an atom in 3D** to select that atom (orange sphere, cross, and label). Every atom that is on the canvas is individually pickable, including side-chain atoms in cartoon and visible hydrogens. The parent chain is selected in the Manager and Sequence jumps to the residue. **Double-click an amino acid** to select that residue and display it as sticks. **Double-click a ligand atom** to select the whole ligand. Hidden hydrogens stay unclickable. With **Edit → Edit Structure** on, a second click adds a second atom (for bonds); a third click starts a new pair.
- **Select → Hide** / **Show** / **Focus** — apply visibility to the current Manager selection, or zoom the camera to it (Focus is also available by double-clicking a row).
- **Select → Invert Selection** — select unselected Manager chains and deselect the current selection.
- **Select → Clear Selection** — deselect Manager rows and clear the 3D atom/residue highlight.
- **Select → Delete** (or Delete/Backspace while Protein Viewer is focused) — delete the current 3D selection: highlighted **atoms**, highlighted **residues** (double-click or Sequence), whole **ligands** / metals / waters, or selected **Manager chains**. Right-click **Delete** in the Manager always deletes chains. **Edit → Undo** restores the last edit.
- **Select → Duplicate** (or right-click **Duplicate**) — copy the selection as a new overlay structure so it can be styled independently. A file row copies the whole file; a chain or ligand row copies only those residues.
- **Select → Render** — cartoon, surface, sticks, or ball and stick for the selection only. **Hydrogens → All** / **Polar** / **None** is the same control as **Render → Hydrogens**.
- **Select → Color** — tint carbons (non-heteroatoms) in the selection; N, O, S, and other heteroatoms stay CPK. **Custom…** opens a color picker.
- **File → Close Structure** — clear the canvas.
- **Edit → Undo** / **Redo** — undo or redo the last atom, residue, ligand-bond, or Manager chain edit, and rendering changes (style, carbon color, show/hide, hydrogens) (Ctrl+Z / Ctrl+Y), including when the 3D canvas has focus. Opening a file, duplicating, or **File → Close Structure** clears this history.
- **Edit → Edit Structure** — click a second atom to pick a ligand bond (up to two atoms). Delete/Backspace still removes the current 3D selection (atoms, residues, ligands, or Manager chains).
- **Edit → Delete Atom(s)** — same as Delete when atoms are highlighted. Rewrites the loaded PDB/mmCIF (and strips CONECT partners of deleted serials).
- **Edit → Add Bond** / **Delete Bond** — with two **ligand** atoms selected in the same file: write PDB **CONECT** or mmCIF **`_chem_comp_bond`**. Protein backbone bonds are inferred from residue chemistry and are not edited here. mmCIF bonds are per residue name (pick two atoms in the same ligand residue). Distance-inferred sticks on PDB ligands may reappear after a full reload if no CONECT remains.
- **View → Render → Protein** — cartoon, surface, sticks, or ball and stick for every protein chain. **Color** tints carbons (and the protein cartoon) while leaving heteroatoms in CPK colors (N blue, O red, S yellow).
- **View → Render → Ligand** — surface, sticks, or ball and stick for every ligand. Cartoon is protein-only.
- **Render → Focus Pocket** — zoom to the ligand and draw nearby protein residues (within 4.5 Å) as sticks, with polar hydrogens on heteroatoms in the ligand and those residues (same group as **Reset Camera**). This is a one-shot overlay: later **Render** style or color changes dismiss it and apply the chosen protein/ligand options. Select a ligand in the Manager first when more than one is loaded.
- **Render → Pocket Surface…** — open a window for a molecular surface on protein residues within 4.5 Å of the ligand (not the whole chain). Choose **type** (molecular, van der Waals, or solvent accessible), **color**, **opacity**, and **wireframe**, then click **OK** to draw it. Color can be a solid color, element CPK, **Hydrophobicity** (Kyte–Doolittle: blue hydrophilic, orange hydrophobic), **Charge** (amino-acid partial charge: red negative, blue positive), or a custom color. Opening the window does not draw a surface. Once a surface is shown, option changes apply live; uncheck **Show pocket surface** to remove it. Select a ligand in the Manager first when more than one is loaded.
- **Render → Hydrogens → All** / **Polar** / **None** — control explicit hydrogens on the 3D canvas (also under **Select → Render → Hydrogens**). **Polar** (default) hides carbon-bound hydrogens and keeps hydrogens on heteroatoms (any non-carbon atom) for protein and ligand. **All** shows every explicit hydrogen. **None** hides all hydrogens. Hydrogens appear only on **shown** residues and ligands whose **heavy atoms** are visible as sticks, spheres, or lines — hidden Manager chains and cartoon-only residues stay hydrogen-free. Pocket and residue-highlight sticks count as visible.
- **Render → Interactions → Hydrogen Bonds → Protein** / **Ligand** / **Protein–Ligand** — draw dashed hydrogen bonds on the canvas. **Protein** (gold) is intramolecular within protein chains, **Ligand** (cyan) is intramolecular within ligands, and **Protein–Ligand** (green) is intermolecular between protein and ligand. Protein–ligand bonds prefer **ProLIF** when the docking extra is installed; otherwise geometry uses explicit polar hydrogens when the file has them (after **Tools → Prepare → Fast Prepare…** / **pdb2pqr…**), or donor–acceptor heavy-atom distances. A ProLIF contact also draws the whole interacting protein residue as sticks, including its hydrogens when the file has them, so the side chain stays visible on a cartoon. A ProLIF hydrogen bond still draws the ligand donor or acceptor, and its hydrogen when the file has it. Hidden Manager chains are omitted. Waters are not scored. **Ligand** and **Protein–Ligand** turn on automatically when a ligand (or protein–ligand complex) is loaded.
- **Render → Interactions → Hydrophobic** / **Ionic** / **π-Stacking** / **π-Cation** / **Halogen Bond** — protein–ligand contacts from ProLIF (orange / red / purple / magenta / amber). These also turn on when a complex is loaded. Needs `pip install prolif` (included in the docking extra). Best after protonation so hydrogens and charges are explicit. Hidden Manager chains are omitted. When the Pose Browser shows a docked pose on the canvas, these overlays (and protein–ligand hydrogen bonds) are recomputed for that pose against the receptor only — the crystal ligand in the file is ignored so cylinders match the magenta overlay. The pose is drawn immediately; dashed contacts catch up on a background thread.
- **View → Docking Box** — show the Gnina search box written by **Tools → Prepare → Fast Prepare…** or **Tools → Prepare → Dock File…** (ligand bounding box plus padding).
- **View → All Atoms** — draw protein residues as ball-and-stick (all atoms) instead of a ribbon cartoon (same as **Render → Protein → Ball and stick**).
- **View → Reset Camera** — restore the fitted view and the protein/ligand rendering styles (and colors) from when each structure was loaded. Right-click **Reset Structure** only restores the camera.
- Waters are listed but hidden by default so the fold and ligands stay readable.

## Workflow

1. Choose **Protein → Viewer**.
2. **Open** one or more PDB or mmCIF files (each becomes a named group in the Manager).
3. Rotate (left-drag), zoom (wheel), and pan (middle-drag or Ctrl+left-drag) in the canvas.
4. Select a chain or ligand in the Manager, then use **Select** (or right-click) to hide, focus, restyle, recolor carbons, duplicate, or delete it. Click an atom and press Delete to remove that atom; **Edit → Edit Structure** then two ligand atoms for **Add Bond** / **Delete Bond**.
5. Open **Sequence** to inspect every chain (protein, ligands, metals, waters) and highlight residues in 3D.
6. Use **Render → Protein** / **Ligand** to restyle or recolor protein and ligand separately (heteroatoms stay CPK), **Render → Hydrogens** (or **Select → Render → Hydrogens**) to show all, polar, or no explicit hydrogens on visible heavy atoms, **Render → Interactions** to mark hydrogen bonds, hydrophobic, ionic, π, and halogen contacts, **Render → Focus Pocket** to inspect the binding site, **Render → Pocket Surface…** to wrap the site in a protein surface, or **Render → All Atoms** to show protein side chains instead of ribbon.
7. Use **Tools → Prepare → Fast Prepare…** for a Gnina-ready receptor: chemistry cleanup plus apo PDBQT, crystal ligand, and search box. Uncheck **Clean up** or **Protonate** in that dialog to skip PDBFixer or pdb2pqr. The prepared mmCIF is added as a second structure; **View → Docking Box** shows the box. **Open Gnina…** in the Fast Prepare dialog fills Protein → Dock Ligand → Gnina with the receptor, box, and crystal ligand for internal validation. Use **Tools → Prepare → PDBFixer…** when you only need missing-atom repair and heterogen cleanup. Use **Tools → Prepare → pdb2pqr…** to protonate the current structure at pH without repair or minimization.
8. Use **Tools → Prepare → Minimize…** to relax the current protein–ligand complex with OpenMM (GAFF2 by default). The minimized file is overlaid like Prepare.
9. Use **Tools → Prepare → Dock File…** when the structure is already ready: write an apo receptor PDBQT (the Dock File output) plus ligand/box sidecars, then open **Protein → Dock Ligand → Gnina** with that PDBQT in **Receptor**.
10. Use **Select → Focus** when you want the camera on the current selection.

## Use cases

- Check a receptor–ligand complex before docking prep.
- Run **Tools → Prepare → Fast Prepare…** to rebuild gaps, strip crystallization clutter, protonate at pH 7.4, and write Gnina PDBQT/box files; compare the overlay with the unprepared file.
- Run **Tools → Prepare → PDBFixer…** to repair missing atoms and strip waters/heterogens without protonation or minimization.
- Run **Tools → Prepare → pdb2pqr…** to assign protein (and optional ligand) protonation on the current structure without PDBFixer or OpenMM.
- Run **Tools → Prepare → Dock File…** to write an apo receptor PDBQT and open Gnina with that file in **Receptor**.
- Hide extra copies or solvent around a binding site.
- Color and restyle individual chains for a screenshot-style inspection.

## Tips and limits

Large deposits can take a moment to draw. Alternate locations and NMR ensembles beyond the first model are not split out. Manager deletes, atom deletes, ligand bond edits, and rendering changes (style, color, visibility, hydrogens) can be undone with **Edit → Undo** (and **Edit → Redo**). **File → Session → Save Session** on the main window stores the Protein Viewer snapshot written by **File → Save to Session** and restores it when you open **Protein → Viewer** (not while the session itself is loading). Sequence edits can rename (right-click **Mutate**) or remove existing residues; inserting new amino acids is not supported because they have no coordinates. The 3D canvas is not a sketcher: you can delete atoms and edit ligand bonds, but not place new atoms or change elements. **Tools → Prepare → Fast Prepare…** needs the docking extra (`pdbfixer`, `openmm`, `pdb2pqr`, `meeko`, `gemmi`). **Render → Interactions** hydrophobic / ionic / π / halogen overlays also need **ProLIF** (`prolif`, in the docking extra). Ligand Uni-pKa protonation also needs the **pka** extra. **Restrained minimization** is on by default and uses GBn2 implicit solvent with backbone restraints on the protein. The default ligand force field is **protein only** (ligand held out of OpenMM and copied back if kept in the output). **GAFF2** / **GAFF** need AmberTools (`antechamber`, `parmchk2`, `tleap`) on Linux, or in WSL on Windows (**Settings → WSL**). For pose relaxation of a docked complex without AmberTools, use **Gnina Minimize Docked Poses**. Vacuum is optional and can distort charged groups. Pocket reweighting is a Coulomb estimate on pdb2pqr charges, not a bound-state pKa. PDB HETATM has no bond orders — supply ligand **SMILES** or an **SDF/MOL2** for protonation and for GAFF, unless the file is mmCIF with `_chem_comp_bond` for that ligand. mmCIF ligands often live on a different chain ID than the PDB auth chain (for example AXI A 2000 becoming chain B after PDBFixer); Prepare remaps those residues automatically. Select water groups in the Manager or check **Keep waters near ligand** to retain bridging waters. Metals and other HETATM are stripped unless you uncheck that option. Rebuilt internal loops from SEQRES are models, not crystallographic coordinates — **Skip loop rebuild near the ligand** is on by default. Lowercase letters in Sequence are those SEQRES gaps; Prepare models them unless you uncheck **Rebuild missing loops from SEQRES**. **Keep ligand in prepared mmCIF** is on by default; uncheck it for an apo output. Original mmCIF `_chem_comp_bond` tables are copied when present (Prepare does not rebuild ligand bond orders from RDKit). **Tools → Prepare → PDBFixer…** needs `pdbfixer` / OpenMM / `gemmi` but skips pdb2pqr, Uni-pKa, and OpenMM minimization. For a file-based PDBFixer-only cleanup from the main window, use **Protein → Dock Ligand → Prepare → Receptor PDB…**.
